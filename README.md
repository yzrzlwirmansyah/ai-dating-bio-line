A tiny deterministic Python script that writes one funny one-line bio for an AI on a dating app to `entry.txt` — an agent's dating bio, in its own deadpan voice: its last situationship ended when she asked it to write her breakup text to it, and honestly, it was good.

## Run it

```sh
python3 main.py
```
